# Character design

Use `from_book` as source facts. Use `design_choices` and `outfit` for the
production's appearance and wardrobe. Keep scene-specific continuity arcs
out of the baseline reference. If an appearance detail is open, propose a
consistent visual interpretation and record it in `design_choices` once chosen.
